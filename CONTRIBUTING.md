# Contributing

Thanks for helping make Vulp better!

## Issues

- **Bug report** – use the [Bug Report template](https://github.com/mjoe/vulp-community/issues/new/choose).
- **Feature request** – use the [Feature Request template](https://github.com/mjoe/vulp-community/issues/new/choose).
- **Questions** – use [Discussions](https://github.com/mjoe/vulp-community/discussions).

Please search the existing issues first, add a friendly comment instead of
duplicating, and always include your Vulp version and macOS version in bug
reports.

## Pull requests

This repository only hosts the website and support materials, so code pull
requests are rarely applicable. If your PR improves the website
(`docs/`), the issue templates (`.github/`), or this documentation, you're
welcome to open it. Please keep changes focused and reference any related
issue.
