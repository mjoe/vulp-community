# Vulp Community

Community, support & ticketing for **Vulp** — the macOS menu bar internet radio player.

This repository is the central place for communication around the app. The
app itself is distributed through the Mac App Store.

## Get help

- **Report a bug** – [Bug Report template](https://github.com/mjoe/vulp-community/issues/new/choose)
- **Request a feature** – [Feature Request template](https://github.com/mjoe/vulp-community/issues/new/choose)
- **Ask a question** – [Discussions](https://github.com/mjoe/vulp-community/discussions)

Please search the issues first — your problem or idea may already be tracked.

## Website

The landing page lives in [`docs/`](docs/) and is published to
<https://mjoe.github.io/vulp-community/>.
